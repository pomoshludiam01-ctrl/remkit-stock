# Склад ремкомплектов — сайт учёта наличия

Простой статичный сайт без сервера и сборки. Два файла:
- `index.html` — сама страница (поиск, фильтры, статусы)
- `data.json` — список позиций (бренд, модель, артикул, количество)

## Как загрузить на GitHub Pages

### Если делаете новый репозиторий
1. Зайдите на github.com → **New repository**
2. Назовите репозиторий, например `remkit-stock` → Create repository
3. На странице репозитория нажмите **Add file → Upload files**
4. Загрузите оба файла: `index.html` и `data.json`
5. Внизу нажмите **Commit changes**
6. Перейдите в **Settings → Pages** (в левом меню)
7. В разделе "Build and deployment" → Source выберите **Deploy from a branch**
8. Branch: `main`, папка `/ (root)` → **Save**
9. Через 1-2 минуты сайт появится по адресу:
   `https://ваш-логин.github.io/remkit-stock/`

### Если хотите добавить в существующий репозиторий (например, рядом с cinus.shop)
Загрузите оба файла в отдельную папку, например `/stock/`, тогда адрес будет:
`https://ваш-домен/stock/`

## Как обновлять наличие

Откройте `data.json` прямо на GitHub (кнопка карандаша — Edit), меняйте поле `"qty"` у нужной позиции, и нажимайте Commit changes. Сайт обновится автоматически при следующей загрузке страницы.

Статусы "В резерве" / "Продано" пользователь сайта переключает сам кликом по плашке — это сохраняется только в его браузере (localStorage), на сервере не отображается и не синхронизируется между разными людьми. Если нужно общее наличие, видимое всем — меняйте `qty` в data.json или пишите туда отдельное поле статуса.

## Структура data.json
Каждая позиция:
```json
{
  "id": 1,
  "brand": "Komatsu",
  "model": "PC200-7",
  "part": "707-99-57160",
  "kit": "Рукоять",
  "kitFull": "Ремкомплект рукояти (стик)",
  "qty": 1,
  "title": "...",
  "desc": "...",
  "cross": "..."
}
```
